# Mom - Everyone can be your Mom 💝

An AI-powered comfort app that provides personalized assistance for food, cleaning, and everyday care. Built with React, Vite, Tailwind CSS, and Framer Motion.

## ✨ Features

- 🤖 **AI Chat Interface** - Chat with your AI Mom for personalized recommendations
- 🎨 **Beautiful Animations** - Smooth transitions and delightful micro-interactions
- 📱 **Mobile-First Design** - Fully responsive and optimized for mobile devices
- 🍝 **Food Recommendations** - Get personalized meal suggestions
- ✨ **Cleaning Services** - Find top-rated cleaning services nearby
- 📚 **Item Exchange** - Discover items matched to your preferences
- 🎯 **Mom Points System** - Earn rewards for interactions

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

Dependencies are already installed. If you need to reinstall them:

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

Build the app for production:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```

## 🛠 Tech Stack

- **React 19** - UI library with modern hooks

- **Tailwind CSS v4** - Utility-first CSS framework
- **Framer Motion** - Production-ready motion library
